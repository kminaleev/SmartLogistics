# SmartLogistics

Лабораторная работа. Java 17, без внешних библиотек.

## Запуск

Из папки проекта выполните `run.bat` в Windows или `sh run.sh` в Linux/macOS.
Нужны JDK 17 или новее и команда `java` в PATH.

## Задания

- `task-1`: Vehicle, Car, Truck, Drone, конструкторы и super().
- `task-2`: CargoItem, перегрузка load(), полиморфный FleetManager.
- `task-3`: ICargo, BaseCargo, три вида грузов, ITrackable и LogisticsCenter.
- `task-4`: Warehouse<T extends ICargo> и Report<T>.

Ветка `main` содержит итог всех четырёх заданий. Для просмотра этапа:
`git switch task-1` (или task-2, task-3, task-4).
В каждой ветке есть запускаемый Main.

Базовая грузоподъёмность Truck передаётся конструктору: методичка не задаёт её числом.
Прицеп добавляет 5000 кг. Загрузка партии выполняется целиком, если хватает
грузоподъёмности; при отказе список и текущий вес остаются прежними.
GPS имитируется фиксированным изменением координат. При заряде ниже 5 процентов
дрон не начинает движение; заряд не становится отрицательным.

Удалённый репозиторий не создан: требуется доступ к учётной записи Git-хостинга.
После создания пустого репозитория выполните:

```sh
git remote add origin <URL_РЕПОЗИТОРИЯ>
git push -u origin --all
```
